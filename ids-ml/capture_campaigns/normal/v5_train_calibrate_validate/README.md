# Normal model-development campaign V5

This final normal campaign contains balanced TCP/SSH, UDP, and ICMP traffic.
Its membership was fixed before use: three captures for fitting, three for
calibration, and four for independent normal validation.

- `normal_v5_fit_001.pcap`: sequential traffic, starting with TCP.
- `normal_v5_fit_002.pcap`: grouped traffic, starting with UDP.
- `normal_v5_fit_003.pcap`: mixed waves, starting with ICMP.
- `normal_v5_cal_001.pcap`: independent sequential calibration traffic.
- `normal_v5_cal_002.pcap`: independent grouped calibration traffic.
- `normal_v5_cal_003.pcap`: independent mixed calibration waves.
- `normal_v5_val_001.pcap`: fresh sequential normal-validation traffic.
- `normal_v5_val_002.pcap`: fresh grouped normal-validation traffic.
- `normal_v5_val_003.pcap`: fresh mixed normal-validation waves.
- `normal_v5_val_004.pcap`: fresh reordered mixed normal-validation rounds.
