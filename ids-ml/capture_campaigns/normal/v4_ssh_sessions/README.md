# Normal SSH-session campaign V4

This campaign adds successful payload-bearing SSH sessions to the normal model
development data.

- `normal_ssh_v4_fit_001.pcap`: failed first sequential SSH attempt.
- `normal_ssh_v4_fit_001_retry1.pcap`: accepted sequential SSH retry.
- `normal_ssh_v4_fit_002.pcap`: grouped SSH fitting sessions.
- `normal_ssh_v4_fit_003.pcap`: concurrent SSH fitting sessions.
- `normal_ssh_v4_fit_004.pcap`: delayed, higher-volume SSH fitting sessions.
- `normal_ssh_v4_cal_001.pcap`: varied sequential SSH calibration sessions.
- `normal_ssh_v4_cal_002.pcap`: grouped SSH calibration sessions.
- `normal_ssh_v4_cal_003.pcap`: concurrent SSH calibration sessions.
